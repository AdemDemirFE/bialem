# /debug

Debug a problem in Bialem.

## Steps

1. Reproduce the problem.
2. Use Codebase Memory to locate relevant code.
3. Identify the affected layer (frontend, API, service, DB, infrastructure).
4. Use the appropriate MCP (PostgreSQL, Docker, Chrome DevTools) if needed.
5. Find the root cause.
6. Apply a minimal fix.
7. Test the fix.
8. Check for regressions.

## Output

- Root cause.
- Fix applied.
- Test results.
