# /review

Review recent changes.

## Steps

1. Inspect `git diff` and `git status`.
2. Check for duplicate code.
3. Check for security issues (secrets, exposed credentials, weak auth).
4. Check for database migration issues.
5. Verify build/test status.
6. Confirm no unrelated files changed.

## Output

- Change summary.
- Issues found.
- Recommended fixes.
