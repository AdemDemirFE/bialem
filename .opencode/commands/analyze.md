# /analyze

Analyze a task before implementation.

## Steps

1. Search Codebase Memory for existing implementations.
2. Identify related entities, services, controllers, components.
3. Map dependencies and relationships.
4. Detect duplication risks.
5. Produce a minimal change plan.

## Output

- Existing files/symbols found.
- Files that need creation or modification.
- Suggested agent(s) and skill(s).
- Open questions (if any).
