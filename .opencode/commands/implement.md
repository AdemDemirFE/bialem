# /implement

Implement a task following Bialem development rules.

## Steps

1. Run `/analyze` to locate existing code.
2. Select the appropriate skill(s) and agent(s).
3. Implement minimal changes.
4. Compile / build.
5. Run targeted tests.
6. Review diff.

## Output

Final result in the standard format:

```text
Yapıldı:
- ...

Değişen:
- ...

Test:
- ...

Kalan:
- ...
```
